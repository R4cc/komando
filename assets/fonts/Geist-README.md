# Geist Sans

Static TrueType fonts from Vercel's [Geist v1.9.2 release](https://github.com/vercel/geist-font/releases/tag/v1.9.2).
Regular (400), Medium (500), SemiBold (600) and Bold (700) are embedded in the app.
The font's internal family name is `Geist`.
